# Tukuk Books Library & Book Clusters Hub (`tukuk-books`)

Welcome to **tukuk-books**, the central repository for storing book metadata, reading lists, literary clusters, and library indexes for [tukuk.org](https://tukuk.org).

## Overview

This repository powers the book discovery engine, categorization, and literary cluster mapping across Tukuk-OS. It organizes extensive book catalogs into structured thematic shelves, enabling fast search and seamless integration into the Tukuk web ecosystem.

## Structure

- `/books`: Structured metadata and reading lists.
- `/clusters`: Thematic book clusters and library hubs.
- `/schema`: JSON schemas for book records and metadata validation.
